# Taby — лендинг

Статический лендинг веб-приложения ресторанной аналитики Taby. HTML, CSS и JavaScript без сборки и внешних зависимостей.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://127.0.0.1:4173/. Если порт занят, замените `4173` на свободный.

## Файлы

- `dist/index.html` — содержание страницы и примеры интерфейса приложения.
- `dist/styles.css` — основные стили.
- `dist/refinements.css` — типографика, сайдбары, адаптивное поведение и анимации.
- `dist/app.js` — переключение разделов при скролле, тумблеры, меню и увеличенный просмотр интерфейса.
- `dist/assets/fonts/TildaSans-VF.woff2` — локальный шрифт Tilda Sans. Файл `TildaSans-VF.ttf` остаётся запасным форматом.

Для размещения на статическом хостинге используйте содержимое `dist/`. Серверная часть и обработка заявок в этот репозиторий не входят.

Примеры интерфейса собраны средствами HTML/CSS/SVG. Все используемые файлы шрифта и стилей хранятся локально.
