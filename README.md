# Taby — лендинг

Статический лендинг веб-приложения ресторанной аналитики Taby. HTML, CSS и JavaScript без сборки и внешних зависимостей.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://127.0.0.1:4173/. Если порт занят, замените `4173` на свободный.

## Файлы

- `dist/index.html` — содержание страницы и примеры интерфейса приложения.
- `dist/styles.css` — все стили страницы.
- `dist/app.js` — закрепление блока возможностей, меню, диалог просмотра, заставка и декоративное поле.
- `dist/assets/fonts/TildaSans-VF.woff2` — локальный шрифт Tilda Sans.
- `dist/assets/og.png` — изображение для превью ссылки, 1200×630.
- `scripts/stamp.py` — при выкладке подставляет версии файлов и публичный адрес сайта.

Для размещения на статическом хостинге используйте содержимое `dist/`. Серверная часть и обработка заявок в этот репозиторий не входят.

В `index.html`, `robots.txt` и `sitemap.xml` адрес сайта записан как `__SITE_URL__`. Workflow GitHub Pages перед загрузкой запускает `scripts/stamp.py`: он подставляет `SITE_URL` из переменной репозитория или, если она пустая, адрес проекта на GitHub Pages. Туда же добавляются версии `styles.css`, `app.js`, шрифта, `og.png` и значка. Локальный сервер эти версии не требует.

## Публикация и поиск

Канонический адрес лендинга: `https://thetaby.ru`. Подробный порядок действий при выкладке — в `docs/vykladka.md`.

Примеры интерфейса собраны средствами HTML/CSS/SVG. Все используемые файлы шрифта и стилей хранятся локально.
